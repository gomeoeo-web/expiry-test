# 期效管家 1.9.1

相機使用 Gemini 3.5 Flash 雲端辨識；使用者無需 API key、測試密碼或下載視覺模型。第一次辨識會說明照片上傳並徵求同意。物品資料與照片縮圖仍儲存在原瀏覽器，既有資料鍵值未更動。

## 本機使用

雙擊「啟動期效管家.bat」以 http://localhost:8080/ 開啟。直接用 file:// 開啟無法完整載入模組或使用雲端辨識。

## 1.9.1 變更

- **大幅擴充生活分類與二級細項**：新增飲品 (drinks)、零食 (snack)、生鮮 (fresh)、保健 (supplement)、美妝 (beauty)、數位 (digital)、文具 (stationery)、運動 (sports)、五金 (tools) 等 28 種生活品類，細項完整涵蓋數百種日常物品。
- **物品使用期限智慧推算與使用日期記錄**：自動判斷各類耗材與消耗品常規建議效期（如鮮奶 12 天、生鮮肉 3 天、菜瓜布 30 天等）；若難以判斷或為耐用品（如手帳、球鞋、背包、書籍），自動切換為記錄使用天數模式（elapsed mode）。
- **修正相機拍攝中點按無法對焦問題**：支援點擊即時對焦 (Tap-to-Focus)，精確傳送觸控座標點測光；鏡頭改以硬體 single-shot 觸發實體對焦步進掃描，並在 2.5 秒後平滑恢復連續對焦；加入微震動觸感回饋與 touch-action: none 防止手勢衝突。
- 測試覆蓋率全數通過，版本號全面升級為 1.9.1。

## 1.9.0 變更

- 拍照、相簿均呼叫雲端辨識，回到既有確認表單，由使用者確認後儲存。
- 未讀到日期、低信心度、離線、逾時、額度用完時，不會自動猜商品或補 30 天效期，可手動填寫。
- 識別前拍攝的高解析圖片用於上傳；儲存本機的照片縮至640px，減少空間占用。
- 修正相機重複事件與晚到串流未釋放問題，防止重複按快門送出多筆請求。
- 移除 MobileCLIP/MobileNet/Tesseract 相機管線與其 CDN、自動模型下載介面、舊測試模式及特徵庫。
- 保留自然語言速記、物品管理、備份、通知與主題功能。網頁關閉後通知的既有限制不因本次升級而改變。
- 設定頁可以撤回雲端照片上傳同意。

## 必須部署正式後端

目前線上 Worker 若仍是需要 TEST_ACCESS_TOKEN 的測試頁，**本 App 尚不能使用它辨識**。需依 [backend/DEPLOY.md](backend/DEPLOY.md) 部署 1.9.0 正式後端。程式不含任何金鑰或開發者密碼。

部署完成後，前端仍使用原 GitHub Pages 網址，後端入口固定為 `https://expiry-ai.gomeoeo.workers.dev/api/recognize`。換網域時需同步修改 cloud-camera.js 的 ENDPOINT 與後端允許來源。

## 用量與資料

預設每個網路 IP 每日10次、每分鐘3次；整個 App 每日100次、每分鐘20次。每日以台灣時間00:00重置。相同 Wi-Fi 共用IP額度。送往模型的嘗試即計次，失敗也不自動退款或重試。

額度由 Cloudflare Durable Object 儲存並原子保留，未設定儲存綁定時停止辨識。這是費用與流量保護，不是帳號驗證；攻擊者仍可能耗尽免費名額。後續大量公開使用時，可再加入 Turnstile / 登入。CORS 不是驗證身分的機制。

後端不儲存照片、提示詞、辨識內容或原始IP。只保留當日用量、加鹽雜湊的來源識別與每分鐘計數。Google/Cloudflare 仍依其服務條款處理請求。API 是否收費依開發者帳號方案而定，次數上限不保證固定金額。

## 建置與驗證

`npm install` 安裝依賴；`npm run build` 同步四個網站檔案到 www，供 Capacitor 使用。

`npm test` 執行後端與額度的離線測試。`npm run test:browser` 使用本機 Microsoft Edge 測試相機／相簿分流、同意、表單、保存、失敗處理與手機尺寸。測試使用模擬 Gemini 回應，不消耗雲端額度。

本機測試不等於 iPhone/Android 實機驗證，也不等於正式雲端已部署。更新前請使用 App 設定頁匯出備份，尤其是不同裝置間移轉時。

## 用量與資料

預設每個網路 IP 每日10次、每分鐘3次；整個 App 每日100次、每分鐘20次。每日以台灣時間00:00重置。相同 Wi-Fi 共用IP額度。送往模型的嘗試即計次，失敗也不自動退款或重試。

額度由 Cloudflare Durable Object 儲存並原子保留，未設定儲存綁定時停止辨識。這是費用與流量保護，不是帳號驗證；攻擊者仍可能耗尽免費名額。後續大量公開使用時，可再加入 Turnstile / 登入。CORS 不是驗證身分的機制。

後端不儲存照片、提示詞、辨識內容或原始IP。只保留當日用量、加鹽雜湊的來源識別與每分鐘計數。Google/Cloudflare 仍依其服務條款處理請求。API 是否收費依開發者帳號方案而定，次數上限不保證固定金額。

## 建置與驗證

`npm install` 安裝依賴；`npm run build` 同步四個網站檔案到 www，供 Capacitor 使用。

`npm test` 執行後端與額度的離線測試。`npm run test:browser` 使用本機 Microsoft Edge 測試相機／相簿分流、同意、表單、保存、失敗處理與手機尺寸。測試使用模擬 Gemini 回應，不消耗雲端額度。

本機測試不等於 iPhone/Android 實機驗證，也不等於正式雲端已部署。更新前請使用 App 設定頁匯出備份，尤其是不同裝置間移轉時。

# 期效管家 (LifeSpan Tracker) ⏳✨

> 全方位生活物品使用期限與更換倒數管家。專為**更換濾網耗材週期**、**食品賞味保存期限**、**家電保固契約**、**日化沐浴品開封天數**量身打造的極致視覺化追蹤系統。

---

## 🌟 核心特色與亮點功能

### 1. 多元情境分類追蹤
- **🔄 更換耗材/濾網**：空氣清淨機 HEPA 濾網、廚房淨水器濾芯、電動牙刷刷頭、冷氣濾網（支援週期倒數與一鍵重置換新）。
- **🥛 食品賞味期限**：鮮乳、乳酪、生鮮調味、常備藥品，精確預警過期。
- **🧴 開封日化/沐浴**：沐浴乳、洗髮精、精華液、防曬乳等 PAO (Period After Opening) 追蹤，清楚顯示「已開封使用 X 天 / 建議剩餘 Y 天」。
- **🛡️ 保固與合約**：手機、筆電、家電購買日起算保固，發票與保固備註一應俱全。
- **📌 其他自訂項目**：各類有使用壽命或定期維護需求的物品。

### 2. 直覺視覺化生命週期
- **動態進度條**：消耗進度百分比（0% ~ 100%），隨時間流逝自動推進。
- **三段色彩狀態燈**：
  - 🟢 **安心良好**：剩餘時間充裕。
  - 🟡 **即將到期**：自訂提早提醒天數（預設 7 天、14 天或 30 天前黃色高亮閃爍）。
  - 🔴 **已過期待更換**：過期天數警示。

### 3. 一鍵「換新/重置週期」
- 更換濾網或新開封時，無需繁瑣重新輸入，只需點擊**「更換濾網 / 換新開封」**：
  - 起始日自動更新為今日。
  - 倒數天數重新開始。
  - 自動累計並記錄於「過往更換紀錄」中（包含歷時天數與自訂備註）。

### 4. 常用生活範本一鍵建立
- 內建生活常見耗材預設：清淨機濾網 (180天)、淨水器濾芯 (90天)、鮮奶 (12天)、沐浴乳 (180天)、防曬乳 (365天)、牙刷刷頭 (90天)、1 年原廠保固 (365天)。

### 5. 隱私與備份
- **100% 本地儲存**：資料儲存在瀏覽器 `localStorage` 中，離線可用、快速反應、隱私安全。
- **JSON 備份匯出與還原**：支援一鍵下載完整 JSON 備份檔，隨時於其他裝置還原匯入。
- **桌面推播通知支援**：整合 Web Notification API，可於到期時收到系統通知提醒。

### 6. 雙主題外觀
- 支援**暗黑模式 (Dark Mode)** 與**極簡明亮模式 (Light Mode)**，隨時於右上角自由切換。

---

## 🚀 如何啟動使用？

### 方式 A：雙擊啟動腳本（最推薦）
直接雙擊執行目錄中的：
`啟動期效管家.bat`
系統會自動啟動本地伺服器並在瀏覽器中開啟 `http://localhost:8080/`。

### 方式 B：直接雙擊網頁
直接使用 Chrome、Edge 或任何現代瀏覽器雙擊打開：
`index.html`
即可立即開始使用！
